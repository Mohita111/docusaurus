# How to build a production site

This guide walks you through creating a production-ready build of your site using TanStack Start and Vite. The production build bundles your code, optimizes assets, and produces the static files you can host or deploy.

## Prerequisites

- Node.js and npm installed on your computer (see System Requirements and Prerequisites)
- The project installed locally with all dependencies (see Installation and Setup Guide)
- A terminal open in the project folder

## Common issues

### Build fails with an error

If the build stops with an error, read the message carefully. It usually identifies the page, setting, or content that needs to be fixed. Correct the issue, then run the build command again. See How to debug errors with detailed context for help interpreting the output.

### Warnings appear during the build

Warnings may appear in the terminal even when the build succeeds. Review each warning to check whether it affects your site, then address it if needed.

### Build takes a long time

Large sites with many pages and assets can take longer to build. Keep the terminal open until the process finishes on its own. To see detailed progress and status messages, see How to view build progress and status messages.
