# How to filter posts by tags

Use tags to find blog posts about a specific topic. When you select a tag, the site shows only the posts that share that tag.

## What you need before you start

- The blog must be available on the site.
- At least one published blog post must have a tag assigned.

## Filter posts by a tag

1. Open the **Blog** section from the main navigation.
2. Open the **Tags** page. You can usually find it linked from the blog home page or the blog menu.
3. Review the list of available tags.
4. Select the tag name for the topic you want to explore.
5. The tag page opens and shows only blog posts that have that tag.
6. If the tag has more posts than fit on one page, use the pager at the bottom to move through the results.

## Expected result

You land on a page that shows a filtered list of posts for the selected tag. The tag name appears at the top of the page, and every post in the list uses that tag.

## Common issues

- **The Tags page does not appear.** The blog may not have any posts with tags yet. Ask the site owner to add tags to blog posts.
- **Selecting a tag shows no posts.** The posts with that tag may be drafts or hidden from public lists. Only published and listed posts appear on tag pages.
- **A tag is missing from the list.** Tags that have no listed blog posts may not appear or may not be useful to open.
