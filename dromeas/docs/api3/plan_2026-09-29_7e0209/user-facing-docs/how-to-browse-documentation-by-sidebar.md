# How to browse documentation by sidebar

Learn how to use the documentation sidebar to find and navigate between pages on a Docusaurus site.

## Before you begin

Make sure you're on a documentation page. You can tell you're on one when you see a **sidebar** — a vertical panel on the left side of the screen with a list of page titles and category names.

You don't need an account or any special permissions to browse the sidebar.

## Browse the sidebar

Use the sidebar to move through the documentation in an organized way. The sidebar groups related pages under category headings, so you can find what you need without guessing.

### Step 1: Open the Docs section

From the site's main navigation bar, select **Docs** or the documentation link. The documentation page loads with the sidebar on the left.

### Step 2: Scan the sidebar for a category

Look down the sidebar. Categories appear as expandable headings that group related pages. A category might show an arrow or chevron next to its name.

### Step 3: Expand a category

Select the category name or its arrow to expand it. The pages inside the category appear below, indented under the category heading. Select the same category again to collapse it and hide those pages.

### Step 4: Select a page

Select any page title in the sidebar. The main area of the page updates to show that page's content. The sidebar automatically highlights the page you're viewing, so you always know where you are.

### Step 5: Move between pages

Continue selecting other page titles in the sidebar to browse through the documentation. You can jump to any visible page at any time — you don't need to read pages in order unless you want to.

You can also use the **Previous** and **Next** links at the bottom of each documentation page to step through the sidebar order one page at a time.

## Expected result

After you select a page in the sidebar:

- The main content area shows the page you selected
- The page title in the sidebar appears highlighted as the active page
- The browser address updates to match the page you're viewing
- Expanded categories stay open so you can see the surrounding pages

## Common issues

### A page doesn't appear in the sidebar

Some pages might be intentionally hidden from the sidebar. If you have the direct link to a page, you can still open it, but you won't find it by browsing the sidebar.

### The sidebar is missing entirely

If you don't see a sidebar, you might be on a page that doesn't belong to the documentation section. Navigate back to the **Docs** section from the main menu.

### Categories are collapsed or expanded

If a category is collapsed, you only see the category name. Select the category name or arrow to expand it and reveal the pages inside. If an expanded category feels cluttered, select it again to collapse it.

### The page doesn't update when you select a link

Check that your browser is connected to the internet and that the site has finished loading. If the page still doesn't update, try refreshing the page and selecting the link again.
