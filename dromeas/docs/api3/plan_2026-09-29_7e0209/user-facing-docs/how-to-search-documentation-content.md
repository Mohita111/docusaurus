# How to search documentation content

Searching the documentation helps you quickly find the page you need without browsing through the sidebar. Search results are contextual, which means they're tailored to the documentation version you're currently viewing.

## Prerequisites

- A web browser
- Access to the documentation site

## Steps to search

1. Navigate to the documentation section of the site.
2. Select the **Search** bar at the top of the page.
3. Type a keyword or phrase related to the topic you want to find.
4. Review the search results that appear below the search bar.
5. Select a result to open that documentation page.

## Expected result

The search results are scoped to the version of the documentation you're currently viewing. For example, if you're browsing version 1.4 of the Android documentation, your results include pages from Android version 1.4. Results also include the preferred or latest version of any other documentation sets on the same site, such as iOS.

Selecting a result takes you directly to that page in the applicable documentation version.

## Common issues

### Search results show a different version than you expected

Search results follow your current location in the documentation. If you want results from a different documentation version, navigate to that version first and then run your search again.

### No results found for your search terms

Try using a broader or more general keyword. Search matches documentation content and titles, so shorter, more common terms are more likely to return useful results than long, specific phrases.

### Search results seem limited to one product

Search is contextual and includes the version you're viewing, plus the preferred or latest version of other documentation sets on the site. To see results from a different product, switch to that product's documentation and search from there.
