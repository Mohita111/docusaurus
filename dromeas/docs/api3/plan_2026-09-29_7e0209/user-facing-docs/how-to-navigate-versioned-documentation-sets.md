# How to navigate versioned documentation sets

This guide helps you explore a documentation site that offers multiple versions of the same product or project. You will learn how to switch between versions, recognize which version you are viewing, and move between pages within a version.

## Prerequisites

Before you begin, confirm the documentation site you are visiting supports versioning. You can recognize a versioned documentation site by these visible signs:

- A version selector appears in the upper-right area of the documentation pages
- A version badge, such as **Next** or **1.0.0**, appears near the top of a page
- A banner appears at the top of a page with text such as **This is unreleased documentation** or **This is documentation for an unmaintained version**

You do not need to sign in or configure anything. Versioned documentation works the same on desktop and mobile browsers.

## Switch to a different version

The version selector is the main control for moving between documentation versions.

1. Open any documentation page.
2. Locate the version selector in the upper-right corner of the page, next to the navigation area.
3. Select the selector. A dropdown appears listing all available versions.
4. Choose the version you want to view.

The page reloads and displays the same documentation topic for the version you selected, if that topic exists in that version.

## Recognize the version you are viewing

After switching versions, you can confirm where you are by checking these visible indicators.

1. Look near the top of the page for a version badge. The badge shows the label of the current version, such as **Next**, **1.0.0**, or **2.0.0**.
2. Check the top of the page for a banner. A banner appears when the current version is marked as unreleased or unmaintained.
3. Look at the version selector in the upper-right corner. The selector shows the name of the version you are currently browsing.

The same documentation topic can be available in multiple versions. The content, sidebar links, and page URL change to match the selected version.

## Navigate pages within a version

The documentation sidebar shows the pages that belong to the currently selected version. Use it to move between topics without leaving that version.

1. On a documentation page, look at the left sidebar.
2. Select any linked page title in the sidebar to open that page.
3. To move between pages in reading order, use the **Previous** and **Next** links at the bottom of each documentation page.

When you navigate with the sidebar or pagination, you stay inside the version you selected. The sidebar content updates automatically to match that version.

## Use search while browsing a specific version

The documentation search respects your current version and shows relevant results first.

1. While viewing a documentation page in a specific version, select the search field.
2. Type your search terms.
3. Review the results. Results from the version you are currently viewing appear first. Results from your preferred or latest version of other documentation sets may also appear.

## Expected result

After you select a version, you should see the documentation content change to that version. The page badge, banner, and sidebar all update to match the selected version. Navigating through sidebar links or pagination keeps you within that version.

## Common issues and solutions

### The page shows a "Page Not Found" after switching versions

Some documentation topics do not exist in every version. If the selected version does not include the page you were viewing, you will see a **Page Not Found** message.

To fix this, return to the version selector and choose the current or latest version, then use the sidebar to find the topic you need.

### A banner appears saying the documentation is unreleased or unmaintained

Banners appear by design for versions that are either still in development or no longer actively maintained. The banner is not an error.

To view stable documentation, select the latest version from the version selector.

### Search results show a different version than the one you selected

Search results include your current version first, but may also show preferred or latest versions of other documentation sets. This is expected behavior for documentation sites that host multiple versioned documentation collections side by side.

If you want results only for your current version, narrow your search terms and check the version label shown with each result.

### The sidebar looks different after switching versions

Each version can have its own sidebar. Pages that are new, removed, or reorganized appear differently between versions. Use the current version's sidebar as the authoritative list of available topics for that version.
