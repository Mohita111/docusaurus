# Docusaurus at a glance

Docusaurus is a modern static site generator built for creating and maintaining documentation websites. It transforms your markdown and MDX content into fast, SEO-friendly HTML that you can deploy anywhere.

## What is docusaurus?

Docusaurus is described as "Easy to Maintain Open Source Documentation Websites." It's a React-powered static site generator that specializes in documentation—whether you're documenting an open source project, shipping a technical product, or building a knowledge base. Instead of managing complex server infrastructure, Docusaurus compiles your content into static files at build time, giving you a lightweight, performant site.

The tool is built with modern web technologies: React for interactivity, MDX for flexible content authoring, and Webpack for bundling. This combination lets you write documentation as plain markdown files while also embedding interactive React components when you need them.

## Who uses docusaurus?

Docusaurus works best for teams and individuals who need to:

- **Document open source projects**, Share how your library or framework works with clear, searchable docs
- **Write technical product documentation**, Explain features, APIs, and best practices for your software
- **Build knowledge bases**, Create organized collections of guides, tutorials, and reference material
- **Maintain living documentation**, Keep docs in sync with your codebase using version control

## Key capabilities

Docusaurus comes with features designed specifically for documentation:

**MDX content support**, Write in markdown with the flexibility to embed React components directly. You're not limited to plain text; you can include interactive examples, diagrams, and custom layouts.

**Blog integration**, Publish timestamped posts with author information, tags, and RSS/Atom feeds. Blog posts are organized chronologically and can be filtered by author or tag.

**Built-in search**, Your site includes search functionality out of the box, so readers can quickly find what they're looking for.

**Multi-version documentation**, Create and manage multiple versions of your documentation simultaneously. Readers can choose which version they want to read.

**Sidebar navigation**, Organize your content into a structured sidebar that helps visitors navigate your docs without getting lost.

**Client-side redirects**, Handle page renames and broken links gracefully without 404 errors.

## Why teams choose docusaurus

**Fast builds**, Docusaurus optimizes the build process so your site compiles quickly, even as your documentation grows. You can use faster bundlers like Rspack for even quicker builds.

**SEO-friendly output**, Static HTML means search engines can easily crawl and index your content. Your documentation gets discovered.

**Beautiful default theme**, The classic theme provides a professional look out of the box. You don't need design skills to launch a great-looking site.

**Extensible plugin system**, Need custom functionality? Plugins let you add new features without modifying core Docusaurus code. The ecosystem includes plugins for blogs, client redirects, image optimization, CSS optimization, and more.

**Low maintenance**, Because everything is static HTML, you don't manage servers, databases, or complex deployments. Git-based workflows let you version-control your documentation alongside your code.
