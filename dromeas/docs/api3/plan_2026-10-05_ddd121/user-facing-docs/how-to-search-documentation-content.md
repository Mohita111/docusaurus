# How to search a documentation content

Searching the documentation helps you quickly find the page you need without browsing through the sidebar. Search results are contextual, which means they're tailored to the documentation version you're currently viewing.

## Prerequisites

- A web browser
- Access to the documentation site

## Steps to search

1. Navigate to the documentation section of the site.
2. Select the **Search** bar at the top of the page.
3. Type a keyword or phrase related to the topic you want to find.
4. Review the search results that appear below the search bar.
5. Select a result to open that documentation page.

## How contextual search works

The search feature uses contextual tags to organize results by documentation version and product. When you search from a specific documentation page, the system automatically applies tags that match your current context.

For example, if you're browsing version 1.4 of the Android documentation, your search applies the tag`docs-android-1.4`. The results then include pages from Android version 1.4, plus the preferred or latest version of any other documentation sets on the same site, such as iOS.

This approach means you'll always see the most relevant results for where you are in the documentation, while still having access to other documentation sets on your site.

## Expected result

Selecting a search result takes you directly to that page in the applicable documentation version. The result page displays with all relevant navigation, sidebar context, and version information intact.

## Common issues

### Search results show a different version than you expected

Search results follow your current location in the documentation. If you want results from a different documentation version, navigate to that version first using the version selector, then run your search again. The search will then scope results to that version.

### No results found for your search terms

Try using a broader or more general keyword. Search matches documentation content and titles, so shorter, more common terms are more likely to return useful results than long, specific phrases. Consider searching for single words rather than exact phrases.

### Search results seem limited to one product

Search is contextual and includes the version you're viewing, plus the preferred or latest version of other documentation sets on the site. To see results from a different product, navigate to that product's documentation first, then search from there. Your search scope will automatically update to match the new context.
