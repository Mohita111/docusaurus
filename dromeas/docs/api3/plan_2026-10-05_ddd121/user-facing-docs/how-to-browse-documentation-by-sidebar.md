# How to browse documentation by sidebar

Learn how to use the documentation sidebar to find and navigate between pages on a Docusaurus site.

## Before you begin

Make sure you're on a documentation page. You can tell you're on one when you see a **sidebar**, a vertical panel on the left side of the screen with a list of page titles organized under category headings.

You don't need an account or any special permissions to browse the sidebar. The sidebar is available to all site visitors.

## Browse the sidebar

The sidebar groups related documentation pages under categories, making it easy to find information without guessing. Categories can be expanded or collapsed to show or hide the pages they contain.

### Step 1: Navigate to the docs section

From the site's main navigation, select **Docs** or the documentation link. The documentation page loads with the sidebar visible on the left.

### Step 2: Identify categories in the sidebar

Scan the sidebar and look for category headings. Categories are expandable sections that group related pages together. A category might display an arrow, chevron, or other expand indicator next to its name.

### Step 3: Expand a category to see pages

Select a category name or its expand icon to reveal the pages inside. The pages appear indented below the category heading. Select the same category again to collapse it and hide those pages from view.

### Step 4: Select a page title

Choose any page title in the sidebar to open it. The main content area updates to display that page's content. The sidebar automatically highlights the current page, so you always know which page you're viewing.

### Step 5: Navigate between pages

Select other page titles in the sidebar to move through the documentation. You can jump to any visible page at any time, you don't need to read pages in sequential order unless you prefer to.

Alternatively, use the **Previous** and **Next** buttons at the bottom of each documentation page to step through pages one at a time in sidebar order.

## Expected result

When you select a page from the sidebar:

- The main content area displays the selected page's content
- The page title in the sidebar appears highlighted as the active page
- The browser address bar updates to reflect the page's URL
- Categories that were expanded remain open, allowing you to see related pages

## Common issues

### A page doesn't appear in the sidebar

Some pages are intentionally hidden from the sidebar for organizational purposes. If you have a direct link to a page, you can still access it, but it won't be discoverable by browsing the sidebar.

### The sidebar is missing entirely

If you don't see a sidebar, you may be on a page outside the documentation section. Navigate back to the **Docs** section using the main navigation menu.

### Categories are not expanding when you select them

Verify that the category name or expand icon is clickable. Try clicking directly on the category name or the arrow icon. If categories appear locked or unresponsive, refresh your browser.

### The page content doesn't change when you select a link

Ensure your browser is connected to the internet and the site has fully loaded. Wait a moment for the page to load, then try selecting the link again. If the issue persists, refresh the page and select the link once more.
